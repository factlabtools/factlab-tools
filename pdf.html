    다시 내려받기

    3단계로 끝납니다

    파일을 올리고, 순서와 페이지를 정하고, 합치면 바로 내려받습니다.

    ① 파일 올리기

    • 점선 칸을 눌러 PDF를 고르거나 끌어다 놓습니다
    • 여러 개를 한 번에 올려도 됩니다
    • 올리는 순간 각 파일의 페이지 수가 표시됩니다

    ② 순서·페이지 정하기

    • ↑ ↓ 버튼으로 합칠 순서를 바꿉니다
    • ‘포함할 페이지’에 1-3,5 처럼 적으면 그 페이지만 들어갑니다
    • 비워 두면 그 파일의 전체 페이지가 들어갑니다

    ③ 합쳐서 내려받기

    • ‘PDF 합치기’를 누르면 바로 다운로드됩니다
    • 결과 카드에서 다시 내려받을 수도 있습니다
    • 페이지 크기는 원본 그대로 유지됩니다

    왜 ‘서버 전송 없음’이 중요한가

    계약서·주민등록등본·병원 서류는 남의 서버에 올리는 순간 통제를 잃습니다.

    이 페이지가 하는 일

    • PDF를 브라우저 메모리에서 읽고, 페이지를 복사해 새 파일을 만듭니다
    • 다운로드는 브라우저가 만든 임시 주소에서 바로 이루어집니다
    • 페이지를 닫으면 올린 파일은 메모리에서 사라집니다
    • 광고·추적 스크립트를 넣지 않았습니다

    직접 확인하는 방법

    • 컴퓨터에서 F12 → Network 탭을 엽니다
    • 그 상태로 PDF를 올려 합쳐 봅니다
    • 파일을 싣는 요청(POST)이 하나도 없고, 페이지를 여는 요청만 보입니다
    • 비행기 모드를 켜도 이미 열어 둔 페이지에서는 합치기가 동작합니다
    ⚠️ 공용 컴퓨터에서는 다 쓰고 페이지를 닫으세요. 파일은 서버에 남지 않지만, 브라우저가 내려받은 결과 파일은 그 컴퓨터의 다운로드 폴더에 남습니다.

    자주 묻는 질문

    합치기 전에 가장 많이 확인하는 6가지입니다.

    정말 파일이 서버로 전송되지 않나요?

    네. 이 페이지는 PDF를 읽고 합치는 일을 브라우저 안의 JavaScript(pdf-lib)로만 처리합니다. 파일을 올리는 요청 자체가 없어서 서버에 남는 사본이 없고, 인터넷을 끊은 상태에서도 한 번 열어 둔 페이지에서는 동작합니다. 브라우저 개발자 도구의 네트워크 탭을 열어 두고 합쳐 보면 파일 전송 요청이 없는 것을 직접 확인할 수 있습니다.

    페이지 범위는 어떻게 적나요?

    각 파일마다 ‘포함할 페이지’ 칸이 있습니다. 비워 두면 전체 페이지가 들어가고, 1-3,5 처럼 쉼표와 붙임표로 적으면 1·2·3·5페이지만 들어갑니다. 3- 처럼 끝을 비우면 3페이지부터 끝까지, -2 처럼 앞을 비우면 처음부터 2페이지까지입니다. 이 칸 하나로 페이지 삭제(남길 페이지만 적기)와 추출(나누기)이 모두 됩니다.

    암호가 걸린 PDF도 되나요?

    암호가 걸린 PDF는 브라우저에서 내용을 풀 수 없어 합칠 수 없습니다. 목록에 ‘암호가 걸린 PDF라 열 수 없습니다’로 표시되며, 그 파일만 빼고 나머지를 합칩니다. 열기 암호뿐 아니라 인쇄·복사만 제한하는 권한 암호도 같은 이유로 읽지 못하는 경우가 많으니, 암호를 푼 사본을 만들어 올려 주세요.

    합친 PDF에 워터마크나 용량 제한이 있나요?

    없습니다. 워터마크를 넣지 않고, 페이지 수·파일 개수·용량에 제한을 두지 않습니다. 다만 처리가 모두 기기에서 이루어지므로 아주 큰 파일(수백 MB)은 기기 메모리에 따라 느려질 수 있습니다.

    스마트폰에서도 쓸 수 있나요?

    네. 파일 앱이나 카카오톡에서 PDF를 저장한 뒤 브라우저로 이 페이지를 열고 ‘PDF 선택’을 눌러 고르면 됩니다. 드래그 앤 드롭은 컴퓨터에서만 되고, 스마트폰에서는 파일 선택 버튼을 쓰면 됩니다.

    한 파일을 여러 개로 나누려면?

    PDF 하나만 올리고 ‘포함할 페이지’에 1-3을 적어 합치면 1~3페이지만 담긴 파일이 나옵니다. 이어서 같은 파일을 다시 올려 4-6을 적으면 나머지 구간을 따로 저장할 수 있습니다. 페이지 범위를 비운 채 합치면 원본 그대로 한 파일이 됩니다.

    쓰는 기술과 한계

    · PDF 읽기·쓰기: pdf-lib 1.17.1 (MIT) — CDN에서 불러와 브라우저 안에서만 실행
    · 파일 선택·다운로드: 브라우저 File API와 Blob URL — 파일이 기기를 떠나지 않습니다
    · 서버·데이터베이스·업로드 엔드포인트를 두지 않았습니다

    합치기는 페이지를 그대로 복사해 새 PDF에 넣는 방식입니다. 아주 오래된 PDF나 특수한 폼(AcroForm)은 입력칸이 일반 텍스트로 바뀔 수 있고, 디지털 서명·북마크·첨부파일은 결과 파일에 남지 않습니다. 서명된 계약서처럼 원본 상태가 중요하면 합치지 말고 원본을 그대로 보관하세요.
